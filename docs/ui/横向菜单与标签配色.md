# 横向菜单与统一标签配色

2026-11-05，按用户参考图实施；不增加图片。

- 帮我搭配的当前菜单继续固定在顶部，菜品改为单行横向文字小卡片，可左右滑动；常规手机约显示三张卡。
- 菜名允许两行，字号 14；菜单标题 16，卡片分类标签 11。保留换一道、临时菜保存和菜单展开/收起；自己调整、确认菜单维持上一轮的窄按钮和字号。
- 卡片高度随临时菜、季节提示和系统字号调整，聊天区仍独立滚动。按钮换菜仍从候选2选择，不调用模型。
- 后续同日精简：菜名不再固定预留两行高度，标签紧随菜名；卡片按实际文字行数增高，常规单行菜名卡片更紧凑。移除标题行重复的人数菜数，滑动提示并入标题行。
- 标题「…」替换为明确「清空」，使用统一暖白深绿风格的底部确认面板；确认后仅重置本餐菜单、对话、备选、临时要求与输入框，保留本次人数菜数及已保存食记。取消、返回键和遮罩关闭不改变菜单。「换整桌」移到下方，与自己调整、确认菜单同排，仍保留本餐要求并使用候选2。
- 后续细调：菜单分类标签下移 4，使上下间距更均衡；「清空」增加细边框，滑动提示靠近标题左对齐。移除聊天区候选数量等内部机制说明，候选数据与换菜逻辑保留。
- 标签统一由 `mobile/src/tags.tsx` 定义。菜单、菜谱列表、自选、食记及确认页复用菜品标签；食材列表季节状态使用同一配色表。顶部筛选选中态沿用深绿。
