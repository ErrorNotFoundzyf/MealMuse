# 吃饭灵感 v0.2.0：离线规则版

## 功能

- 自动搭配：按人数、荤素汤数量、食材季节搭配。修改本次配置后重新搭配，保留额外选中的甜点和水果。
- 自己挑：自由选菜，菜单与自动搭配页同步；可保留已选菜，再补齐其余类别。
- 脑洞一道菜：从现有菜谱随机抽取；预览、再抽取、加入本餐，不创造新菜谱。
- 家里有啥：搜索食材及已有别名、多选；按主要食材区分“可直接做”和“还差一样”，明确列出缺料。调料不作为缺料门槛，仍需做饭时核对。
- 本餐菜单：按汤、荤菜、素菜、主食、其他、 水果、甜点顺序展示；连续编号，支持换一道、删除、加菜和确认。
- 保留本地食材、菜谱、家庭配置、食记、备份与恢复。新版界面不提供 AI 对话和 API Key 设置，运行不调用模型。

## 日期与推荐边界

自动搭配、换菜、脑洞一道菜及家里有啥，均排除北京时间今天及前三天已确认的菜，共四个自然日。例如 11 月 13 日排除 11 月 10—13 日，11 月 9 日可再次推荐。删除的食记不计入。

默认使用当季与全年主要食材，允许非当季开关对三个推荐入口生效。规则候选不足会提示，不自动放宽近期规则。手动选择允许重复；自动补齐保留手选菜，对新补的菜执行上述推荐规则。

删除只影响当前草稿，不删除菜谱或历史食记。删除后可直接确认剩余菜品，或主动点击补齐。水果与甜点不计入基础荤素汤配额，整桌更换保留其份数。

## 升级与验收

- 正式包沿用 com.family.todayeat 和已有发布签名；覆盖安装升级，先不要卸载。
- 升级保留手机数据库；旧对话草稿保留已选菜，清理失效的对话和候选状态。
- 家里食材的选择保存在本机，可随时增删；不作为实时库存，不记录数量或保质期。
- 代码检查：TypeScript；32 项本地测试覆盖原有功能、新随机/食材匹配接口、四天边界、跨年/闰年、保留已选补齐、修改配置与菜单确认。
- 本次构建时未连接手机，排版、点击和覆盖安装后的真机效果需安装新版验证。
